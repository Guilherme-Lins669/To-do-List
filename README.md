# TODO LIST

Aplicação acadêmica de lista de tarefas.

**Tecnologias:** HTML5 + CSS3 + JavaScript (puro, sem frameworks e sem backend)

## Como executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.
Não é necessário instalar nada, não há servidor, banco de dados ou dependências.

## Funcionalidades

- Adicionar tarefas com título e prioridade (Alta, Média, Baixa)
- Limite de 10 tarefas
- Marcar/desmarcar tarefa como concluída
- Editar título da tarefa
- Excluir tarefa
- Reordenar tarefas por drag and drop
- Ordenação automática por prioridade
- Mensagens de feedback (toast)
- Persistência local dos dados no navegador (`localStorage`)
